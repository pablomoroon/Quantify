Configura tu acceso privado

Para usar esta app fuera de Claude, en cualquier dispositivo, con tus propios datos privados y sincronizados, necesita conectarse a una base de datos gratuita tuya (Firebase de Google). Son 5 minutos, una sola vez.

  1. Entra en console.firebase.google.com y crea un proyecto nuevo (gratis).
  2. En el menú del proyecto, ve a Compilación → Authentication, pulsa "Comenzar" y activa el proveedor Correo electrónico/contraseña. Activa también el proveedor Google desde la misma pantalla.
  3. Ve a Compilación → Firestore Database, crea la base de datos (modo producción) y en "Reglas" pega esto y publica: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
  4. Ve a ⚙️ Configuración del proyecto → pestaña "General" → sección "Tus apps" → icono </> (Web) → registra la app y copia el objeto firebaseConfig.
  5. Pega esos valores en el archivo HTML de esta app, al principio del <script>, sustituyendo el objeto firebaseConfig de ejemplo.
  6. Guarda el archivo y ábrelo en tu navegador (o súbelo gratis a Netlify, GitHub Pages o Firebase Hosting para tener una URL). Crea tu cuenta la primera vez con tu email y una contraseña, y listo: entra con esa misma cuenta desde cualquier dispositivo.

Solo tú tendrás esa contraseña, así que solo tú podrás entrar y ver tus datos.
